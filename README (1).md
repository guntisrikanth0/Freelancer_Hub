# 📌 About the Project

**Freelance Connect** is a full-stack MERN web platform developed to simplify collaboration between freelancers and clients.

Clients can create and manage projects, while freelancers can explore available opportunities and send proposals. The platform also supports secure authentication, live communication, and role-based dashboards to streamline the freelancing experience.

---

# ✨ Core Features

## 👤 Client Functionalities
- User Registration & Secure Login
- Publish New Projects
- Update and Manage Projects
- Review Freelancer Applications
- Approve or Decline Proposals

---

## 💼 Freelancer Functionalities
- Search Available Projects
- Apply with Proposals
- Monitor Proposal Status
- Real-Time Messaging
- Profile Management

---

## 🔐 Platform Features
- JWT Authentication System
- Password Encryption using bcryptjs
- RESTful API Architecture
- Responsive UI Design
- MongoDB Database Connectivity
- Socket.io Real-Time Chat Integration
